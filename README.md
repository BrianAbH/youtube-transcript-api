# youtube-transcript-api
App web local en Python (Flask) hecha en claude que recibe el link de YouTube y devuelve la transcripción.



Instalación
Requiere Python 3.10 o superior.

pip install -r requirements.txt

python app.py

Notas
Funciona con videos que tengan subtítulos (manuales o autogenerados).
Acepta links youtube.com/watch?v=, youtu.be/, /shorts/, /embed/ y /live/.
